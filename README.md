# Saffron & Stone — Internship Week 4 Project

A complete responsive multi-page restaurant website built with semantic HTML5, CSS3 and vanilla JavaScript.

## Pages
- `index.html` — Home / business introduction
- `menu.html` — Restaurant menu
- `booking.html` — Contact and table booking form

## Technical requirements covered
- 3 HTML pages
- Responsive/mobile-first layout
- Semantic HTML5 structure
- Navigation between pages
- CSS styling and responsive breakpoints
- JavaScript mobile navigation
- JavaScript form validation
- Date validation and minimum booking date
- Accessible labels, button states and live status message
- Optimized remote image loading with `fit=crop`, width and quality parameters
- Basic performance practices such as deferred JavaScript
- Ready for GitHub Pages or Netlify deployment

## How to run
Open `index.html` in a browser, or use VS Code Live Server.

## Deployment
Upload this folder to a GitHub repository and enable GitHub Pages, or drag the folder into Netlify.
